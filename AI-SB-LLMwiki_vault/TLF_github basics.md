
I will be working with this repo as a personal vault that is pushed to from my own devices. 
## personal computer instructions

it is set up already on my 2026 macbook air (M5) and the terminal code to push an update from this vault is 

```
git add .
git commit -m "Add new notes"
git push
```

## work computer instructions

run this code in the terminal from within the folder where you want the vault (cd ...)

### clone the repo onto the computer 

```
git clone https://github.com
```

### update the repo

```
git pull
```
